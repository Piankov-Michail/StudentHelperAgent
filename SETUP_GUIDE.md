# 🎓 StudentHelperAgent - Руководство по настройке

## Описание

StudentHelperAgent - это AI-powered веб-приложение для автоматической транскрибации видео и аудио лекций с созданием структурированных конспектов. Приложение использует:
- **Whisper** (через Hugging Face) для распознавания речи
- **Ollama** для генерации конспектов и ответов на вопросы

---

## 📋 Требования

- Docker и Docker Compose (для запуска через контейнеры)
- Или Python 3.10+ (для локального запуска)
- Аккаунт на [Hugging Face](https://huggingface.co)
- (Опционально) Аккаунт на [Ollama](https://ollama.com) для использования облачных моделей

---

## 🔑 Получение API токенов

### 1. Hugging Face Token (обязательно)

Токен Hugging Face необходим для использования модели Whisper для транскрибации аудио.

#### Шаги:

1. **Зарегистрируйтесь или войдите** на [Hugging Face](https://huggingface.co)

2. **Перейдите в настройки токенов:**
   - Откройте [https://huggingface.co/settings/tokens](https://huggingface.co/settings/tokens)
   - Или: Нажмите на аватар → Settings → Access Tokens

3. **Создайте новый токен:**
   - Нажмите кнопку **"New token"** или **"Create new token"**
   - Введите имя токена (например, `StudentHelperAgent`)
   
4. **Выберите тип токена:**
   - Выберите **"Read"** (достаточно для использования моделей)
   - Или **"Write"** (если планируете загружать свои модели)

5. **Настройте разрешения (Permissions):**
   
   Для работы с Whisper необходимо выбрать следующие разрешения:
   
   - ✅ **Read access to contents of all public gated repos you can access**
   - ✅ **Read access to contents of all repos you can access**
   
   Или просто выберите тип **"Read"** - этого достаточно для большинства случаев.

6. **Создайте токен:**
   - Нажмите **"Generate token"**
   - **ВАЖНО:** Скопируйте токен сразу! Он будет показан только один раз.
   - Токен выглядит примерно так: `hf_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

7. **Сохраните токен в безопасном месте**

---

### 2. Ollama API Key (опционально)

Ollama API Key нужен только если вы хотите использовать облачные модели Ollama. Если вы используете локальный Ollama сервер, этот токен не требуется.

#### Шаги:

1. **Зарегистрируйтесь или войдите** на [Ollama](https://ollama.com)

2. **Перейдите в настройки API ключей:**
   - Откройте [https://ollama.com/settings/keys](https://ollama.com/settings/keys)
   - Или: Нажмите на аватар → Settings → API Keys

3. **Создайте новый API ключ:**
   - Нажмите кнопку **"Create API Key"** или **"New API Key"**
   - Введите имя ключа (например, `StudentHelperAgent`)

4. **Скопируйте ключ:**
   - **ВАЖНО:** Скопируйте ключ сразу! Он будет показан только один раз.
   - Ключ выглядит примерно так: `ollama_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

5. **Сохраните ключ в безопасном месте**

## 🚀 Запуск приложения

### Вариант 1: Docker (рекомендуется)

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Piankov-Michail/StudentHelperAgent.git
   cd StudentHelperAgent
   ```

2. **Создайте файл `.env`:**
   ```bash
   cp .env.template .env
   ```

3. **Отредактируйте `.env` файл:**
   ```env
   # Database
   DATABASE_URL=postgresql+asyncpg://postgres:postgres@db:5432/student_helper
   
   # JWT Secret (сгенерируйте случайную строку)
   JWT_SECRET=your-secret-key-here
   
   # Ollama (если используете локальный сервер)
   OLLAMA_BASE_URL=http://host.docker.internal:11434
   ```

4. **Запустите контейнеры:**
   ```bash
   docker-compose up -d
   ```

5. **Откройте приложение:**
   - Перейдите на [http://localhost:8000](http://localhost:8000)

### Вариант 2: Локальный запуск

1. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Настройте PostgreSQL** и создайте базу данных

3. **Создайте `.env` файл** с настройками подключения к БД

4. **Запустите приложение:**
   ```bash
   uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
   ```

## ⚙️ Настройка токенов в приложении

После запуска приложения необходимо добавить API токены в настройки:

### Шаги:

1. **Откройте приложение** в браузере: [http://localhost:8000](http://localhost:8000)

2. **Зарегистрируйтесь или войдите** в систему

3. **Откройте настройки:**
   - Нажмите на **значок шестерёнки** (⚙️) в левом верхнем углу боковой панели
   - Или найдите кнопку **"Настройки"** в меню пользователя

4. **Введите токены:**

   **🤗 Hugging Face Token (обязательно):**
   - Вставьте токен, полученный на [https://huggingface.co/settings/tokens](https://huggingface.co/settings/tokens)
   - Формат: `hf_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   - Этот токен нужен для транскрибации видео через Whisper

   **🦙 Ollama API Key (опционально):**
   - Вставьте ключ, полученный на [https://ollama.com/settings/keys](https://ollama.com/settings/keys)
   - Формат: `ollama_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   - Нужен только для использования облачных моделей Ollama
   - Если вы используете локальный Ollama сервер, оставьте это поле пустым

5. **Сохраните настройки:**
   - Нажмите кнопку **"Сохранить"**
   - Вы увидите уведомление об успешном сохранении

6. **Проверьте работу:**
   - Попробуйте загрузить видео или аудио файл
   - Приложение должно успешно транскрибировать его

## 🎬 Использование приложения

### 1. Транскрибация видео/аудио

1. **Выберите режим:**
   - В верхней части экрана выберите **"🎬 Транскрибация видео"**

2. **Прикрепите файл:**
   - Нажмите на значок скрепки (📎) в поле ввода
   - Выберите видео или аудио файл
   - Поддерживаемые форматы: MP4, AVI, MOV, MKV, WebM, MP3, WAV, M4A, FLAC

3. **Добавьте комментарий (опционально):**
   - Введите текст в поле ввода (например, "Создай конспект этой лекции")
   - Или оставьте пустым - приложение автоматически создаст конспект

4. **Отправьте:**
   - Нажмите кнопку отправки (стрелка вверх ↑)
   - Дождитесь завершения обработки

5. **Получите результат:**
   - Приложение покажет:
     - 📝 Полную транскрипцию
     - 📚 Структурированный конспект с ключевыми темами
     - 🎯 Выделенные важные моменты
     - ⏰ Дедлайны и задания (если упоминались)

### 2. Чат-помощник

1. **Выберите режим:**
   - В верхней части экрана выберите **"💬 Чат-помощник"**

2. **Задайте вопрос:**
   - Введите вопрос в поле ввода
   - Нажмите Enter или кнопку отправки

3. **Получите ответ:**
   - AI-помощник ответит на ваш вопрос

### 3. Управление сообщениями

При наведении курсора на сообщение появляются кнопки действий:

**Для пользовательских сообщений:**
- 📋 **Копировать** - скопировать текст сообщения в буфер обмена
- 🔄 **Повторить (Retry)** - повторно отправить запрос (удалит все последующие сообщения)
- 🗑️ **Удалить** - удалить сообщение и все последующие

**Для сообщений ассистента:**
- 📋 **Копировать** - скопировать текст ответа в буфер обмена

### 4. Управление чатами

- **Создать новый чат:** Нажмите кнопку **"+ Новый чат"** в боковой панели
- **Переключиться между чатами:** Кликните на чат в списке истории
- **Удалить чат:** Наведите курсор на чат → нажмите значок корзины 🗑️
- **Экспорт чата:** Нажмите кнопку **"Экспорт"** (📋) в верхней панели

## 🔧 Устранение неполадок

### Проблема: "Ошибка транскрибации"

**Решение:**
1. Проверьте, что Hugging Face токен введён правильно в настройках
2. Убедитесь, что токен имеет права "Read"
3. Проверьте формат файла (должен быть видео или аудио)
4. Проверьте размер файла (не более 500 МБ)

### Проблема: "Кнопки Retry/Delete не работают"

**Решение:**
1. Очистите кэш браузера (Ctrl+Shift+R)
2. Перезапустите Docker контейнер: `docker-compose restart`
3. Убедитесь, что используете последнюю версию приложения

### Проблема: "Ollama не отвечает"

**Решение:**
1. Если используете локальный Ollama:
   - Убедитесь, что Ollama запущен: `ollama serve`
   - Проверьте, что модель загружена: `ollama pull llama2`
2. Если используете облачный Ollama:
   - Проверьте, что API ключ введён правильно
   - Убедитесь, что у вас есть доступ к облачным моделям

### Проблема: "Браузер показывает старую версию"

**Решение:**
1. Откройте DevTools (F12)
2. Перейдите на вкладку Network
3. Поставьте галочку "Disable cache"
4. Обновите страницу (Ctrl+Shift+R)

## 📚 Дополнительная информация

### Поддерживаемые форматы файлов

**Видео:**
- MP4, AVI, MOV, MKV, WebM

**Аудио:**
- MP3, WAV, M4A, FLAC

### Ограничения

- Максимальный размер файла: 500 МБ
- Максимальная длительность: 3 часа
- Поддерживаемые языки: русский, английский, и другие (зависит от модели Whisper)

### Безопасность

- Все токены хранятся в зашифрованном виде в базе данных
- Файлы хранятся локально и не передаются третьим лицам
- Используйте сильные пароли для учётных записей
